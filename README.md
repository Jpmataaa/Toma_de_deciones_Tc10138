# Toma_de_deciones_Tc10138

## ¿Que es?
Es un sistema interactivo de soporte para la toma de decisiones conscientes que combina la reflexión guiada del usuario con la precisión analítica de un algoritmo. A diferencia de un test automatizado tradicional, es un programa de autoevaluación adaptativa que integra modelos psicológicos de decisión

## ¿Para que sirve? 
Eliminar la parálisis por análisis y el sesgo de la espontaneidad: Evita tomar decisiones impulsivas por desesperación o dejarlas al azar cuando la mente se abruma.

## ¿como se usa?
Definición de opciones: El usuario ingresa las alternativas a evaluar (Opción A, B, C...).
Cuestionario y calificación: Se responden preguntas reflexivas y se asigna un valor numérico a cada criterio de las opciones.
Procesamiento algorítmico: El programa calcula, multiplica y pondera las calificaciones automáticamente.
Resultado y diagnóstico: Muestra la mejor opción según la evaluación y explica visualmente por qué ganó.
